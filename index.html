사용 목적

고객정보를 AI 전용 난수로 바꿔, 원문 없이 AI로 통계·분석합니다

실제 원장·CRM·고객 데이터를 AI로 분석하고 싶어도 고객정보를 AI에 그대로 넣을 수는 없습니다. 이 도구는 고객번호·계좌번호·이름을 이번 작업에서만 쓰는 난수로 바꿔 AI에 넘기고, AI가 돌려준 결과는 오프라인에서만 원래 고객과 다시 연결합니다.

무엇을 하나

원장·CRM·고객 엑셀의 식별정보만 난수로 바꿉니다. 금액·날짜·종목 같은 분석 값은 남기므로 AI가 고객별 건수·합계·추이 같은 통계를 그대로 계산합니다.

어떻게 지키나

실행할 때마다 새로 뽑는 1회성 난수라 AI가 여러 번 받은 자료를 이어 붙여 학습하거나 추적할 수 없습니다. 원래값과 난수의 대응표는 공유 폴더 밖, 오프라인에만 둡니다.

어디에 쓰나

AI로 고객 통계·분석을 낼 때, 그리고 오프라인 망에서 돌릴 사내 분석 툴을 만들 때 실제와 같은 구조의 데이터로 개발·검증할 때 씁니다.

How to Use

  1. 가명처리 저장

    시트별로 고객번호·이름·계좌번호를 체크하고 ‘원본 양식 + AI 자료 저장’을 누릅니다. 원래값·난수 대응표 엑셀은 공유 폴더 밖에 따로 저장됩니다.

  2. AI에는 Markdown만

    결과 폴더의 AI_분석자료.md만 AI에 넣습니다. 치환본·.opmap·키는 넣지 않습니다.

  3. 답변 저장

    AI가 가명값을 그대로 둔 JSON으로 답하게 하고, 답변을 .json·.txt로 저장합니다.

  4. AI 결과 매칭

    저장 때 만든 .opmap(이 PC) 또는 대응표 엑셀(다른 오프라인 PC)과 답변 파일을 고르면 원래 고객번호와 연결된 새 XLSX가 나옵니다.

1회성 난수

실행할 때마다 패턴 없는 새 난수로 바뀝니다. AI가 여러 번 받은 자료를 이어 붙여 학습할 수 없습니다.

실행 안의 규칙

한 번 돌린 결과 안에서는 같은 고객번호·계좌번호가 같은 값입니다. 고객별 건수·합계 같은 계산은 그대로 됩니다.

이 시연에서 만든 AI_분석자료.md입니다. AI에 첨부해 고객별 통계를 요청해 보세요.

설치 없이 EXE를 실행하세요.
인터넷 연결은 필요 없습니다.

읽을 수 있는 파일

XLSX · XLSM · XLTX · XLTM
CSV · TSV · TXT

선택한 시트만 읽습니다. 공백·병합된 열 제목은 그대로 두고, 여러 표·숨김·세로 병합이 있으면 사용할 범위를 선택하세요.

XLS·ODS·암호 파일은 XLSX 사본으로 저장해 주세요. 수식은 저장된 계산 결과를 읽습니다.

처리가 안 될 때

화면의 위치·원인·해결 방법을 확인하세요. 다른 시트를 선택해서 계속할 수 있습니다.

중단된 저장은 다음 실행 때 정리합니다. 취소하면 정지가 끝난 뒤 다음 파일을 여세요. 확인이 필요한 파일은 보존하며, 새 파일명으로 저장할 수 있습니다.
